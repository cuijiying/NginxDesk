默认站点：http://127.0.0.1:8080 · 首次使用请点击「启动服务」。

工作目录

配置与日志保存在用户数据目录，升级软件时保留。关闭窗口时可选择保持服务运行。

已保存

保存前自动备份，校验失败自动回滚。主配置需保留 pid logs/nginx.pid; 。相对路径基于工作目录。

创建站点配置

生成独立的 server 配置，校验通过后保存到 conf/sites。

新站点监听所有网络接口；请按实际需求配置防火墙和访问限制。

暂无日志

显示最近 64 KB，每 5 秒刷新。自定义日志路径请从工作目录查看。
