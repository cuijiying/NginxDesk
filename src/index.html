服务操作

当前连接的 nginx 实例
默认站点：http://127.0.0.1:8080 · 首次使用请点击「启动服务」。

工作目录

配置与日志保存在用户数据目录，升级软件时保留。关闭窗口时可选择保持服务运行。

已保存的实例

默认使用软件自带的本机托管实例。也可以连接到本机或远程已经存在的 nginx；切换实例不会自动停止另一边的服务。

添加连接

本机探测会查找正在运行的 nginx、PATH 以及常见安装路径，并用 nginx -V 填写 prefix 与配置路径。

已保存

保存前自动备份，校验失败自动回滚。本机托管实例的主配置需保留 pid logs/nginx.pid; 。

创建站点配置

生成独立的 server 配置，校验通过后保存到 conf/sites。

新站点监听所有网络接口；请按实际需求配置防火墙和访问限制。

暂无日志

显示最近 64 KB，每 5 秒刷新。自定义日志路径请从工作目录查看。

官方版本

从 nginx.org 下载官方发行包并替换当前引擎。安装或删除前需先处理当前版本：正在使用的引擎不能删除；配置、日志与站点文件会保留。
